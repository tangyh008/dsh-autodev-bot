# DevBot v0.5 UI 重设计需求（移动端工作台 + 会话历史风格统一）

> 状态：需求分析（Lead 定稿）｜版本目标：0.5.0
> 输入：用户两张截图 + 文字需求；现有实现 client.js v0.4.0。

## 1. 背景与问题证据

用户要在手机上使用 DevBot，并希望 DevBot 的会话历史与 DSH 主会话风格统一。

问题 A（移动端布局坏）：
- 工作台是固定三栏：项目列表 196px + 聊天 flex + 侧栏 252px（client.js styles.teams / styles.side）。
- 手机可用宽度约 375–430px，扣掉 DSH 外壳后三栏必然横溢：聊天列被压到≈0，底部状态文案逐字竖排，阶段门右侧被裁切，顶栏按钮拥挤；无横向滚动可救。
- 根因：布局按桌面像素写死，没有按「容器宽度」重排；flex 子项缺 min-width:0 与 white-space 约束。

问题 B（会话历史风格割裂）：
- 当前所有发言都是气泡（border + bg-overlay），assistant 也是气泡，头像+粗体名字+时间堆在每条消息上方；正文 white-space:pre-wrap，markdown（## 合并结果、- 列表）原样显示。
- DSH 主会话：assistant 无气泡、无头像、整列正文 + markdown；用户右侧浅色胶囊；工具/过程行 24px 紧凑行；"已完成，用时"折叠行；13–14px 克制排版、低对比边框。

## 2. 目标与非目标

目标：
1. 手机（375–430px）可完整使用工作台：看群聊、看阶段门/任务/成员、切项目、上滑加载，无横溢/无竖排/无裁切。
2. 会话历史视觉与 DSH 主会话同族：同一套 token、同一字号/行高/间距节奏、markdown 直排、用户胶囊、紧凑系统/动作行。
3. 桌面三栏不回退。

非目标：
- M2 能力：页面内发消息、新建项目、未读 badge、点成员跳 DM。
- 不改 DSH 源码/Host 接口；不加 npm 依赖；不引入构建。
- 不新增"群日志"第二真值；时间线仍是各会话持久日志的合并投影。
- 不改 controller 的 retain/release/attach、滚动跟随、settle 去重语义。

## 3. R1 移动端响应式工作台

按容器宽度（.devbot-root 上 container-type:inline-size + @container），不按视口宽度，因为 DSH 外壳侧栏会占宽。

| 容器宽度 | 布局 |
|---|---|
| ≥900px | 三栏：项目列表 196 / 群聊 flex / 侧栏 252（现状） |
| 560–899px | 两栏：群聊 flex + 侧栏 240；项目列表收进顶栏"项目 ▾"下拉（点击浮层，含遮罩、可关闭） |
| <560px | 单栏：顶栏 44–48px（返回｜项目名 ▾｜刷新）+ 分段 tabs（群聊/阶段门/任务/成员）+ 内容区占满 + 底部状态条；项目切换走底部抽屉/浮层 |

要求：
- 群聊区独立滚动；切 tab 不丢滚动位置、不丢选中团队（状态在 controller）。
- 顶栏/底栏固定，不随 chat 滚动；底部留 env(safe-area-inset-bottom)。
- 触控目标 ≥40×40（分段、按钮、项目项）；字号不低于 13px。
- 底部状态文案单行省略：上滑加载更早 / 正在加载更早… / 已到最早，禁止竖排（white-space:nowrap + min-width:0）。
- 代码块/表格自身横向滚动，页面不横溢。
- 保留顶部 --dsh-frame-top-clearance 留白。
- 空态/加载/错误态在单栏下仍可读。

## 4. R2 会话历史与 DSH 主会话同族

- assistant：无气泡、无头像、无名字；整列 markdown 正文；14px/24px；块间 16px；与相邻行 6–12px。
- 用户：右对齐胶囊，--dsw-specific-bubble、圆角 20、padding 10×16、14/22、上限 min(70% 列宽, 82%)；无头像。
- 成员发言（群聊需要身份）：小头像 18–20px + 名字 12px + 时间 11px，仅在发送者变化/间隔>5min 时显示；正文同 assistant 直排，不用彩色气泡；角色色只用于小圆点/头像。
- 系统/任务事件：居中 11–12px tertiary 低对比单行，无边框气泡；可点击展开详情（任务摘要）。
- 派单/动作行：24px 紧凑行（图标 14 + 标题 13 + 摘要省略），可展开；不重复渲染正文（正文以目标会话投递副本为准）。
- 流式：沿用现有行，样式与 assistant 一致 + "输入中"指示；settle 后不叠字。
- markdown 子集：标题 h1–h3、段落、粗/斜体、行内代码、围栏代码块、有序/无序列表、引用、链接、hr；全部文本先转义，链接只允许 http(s)/mailto/#；不执行 HTML。
- 日分隔保留；时间显示 HH:mm，跨日 M月D日 HH:mm。
- 深色默认；浅色可读；颜色只用 --dsw-alias-* / --dsw-specific-bubble / --dsw-radius-*，禁止硬编码色值（HANDOVER 配色事故）。

## 5. R3 行为与数据不回退
- controller 逻辑不改：attach 增量、失败重试、换团队整体释放、loadOlder、nextStick/shouldFollowBottom 保持。
- 现有 12 个 Node 测试全绿。
- 页面卸载释放 retain；切 tab/切面板不新增 retain。

## 6. R4 验证
- npm test 全绿 + 新增 markdown/断点/无溢出单测。
- Playwright（DSH checkout 自带）真实渲染：375/390/430/768/1280/1440 宽截图；断言 scrollWidth<=clientWidth、chat 区宽>200 高>300、无竖排（元素高<40 且宽>高）、触控目标≥40、深/浅色可读。
- 桌面 1280/1440 三栏回归（项目列表/侧栏可见）。
- 用户真机最终确认。

## 7. 已定决策（Lead）
1. 不加依赖：markdown 用 client.js 内置子集渲染器（返回 React 元素，AST 可单测）。
2. 不改 DSH 源码/Host；只改 client.js 渲染层 + 注入 CSS。
3. 桌面三栏保留；移动端重排，不做第二套页面。
4. 群聊仍为合并会话投影；不造群日志。
5. 版本 0.5.0。
