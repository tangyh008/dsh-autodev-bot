实现要点（供 task-4 参考）

  • .devbot-root { container-type: inline-size }，三断点用 @container；不用 viewport media query。
  • 群聊是唯一滚动容器：flex:1; min-height:0; overflow-y:auto；顶栏 / tab / 状态条 flex:none。
  • 状态条 white-space:nowrap + min-width:0 + text-overflow:ellipsis；底部叠加 env(safe-area-inset-bottom)。
  • 切 tab 只 toggle hidden，四视图保持挂载，scrollTop 天然保留；切回群聊仅在原贴底时回到底部。
  • 固定件尺寸：顶栏 48 · 分段 tab 44 · 底部状态条 30（+ safe-area）；列表行 ≥56，可点元素 ≥40×40。
  • 项目抽屉高 ≤ 70%，内部滚动；点遮罩 / 关闭 / Esc 关闭且不切换；当前项加勾。
  • 切项目后时间线回新项目最新；示例稿不切换示例数据，交互仅演示 IA。

设计自查（截图时自动测量）

  • 页面 scrollWidth ≤ clientWidth；工作台内部同样无横溢。
  • 群聊列宽 ≥ 280（390 宽时约 358）；状态条单行，高度 ≤ 24。
  • 四段 tab 标签不换行、不竖排；长标题两行截断；长代码块消息内横滚。
  • 触控目标：顶栏按钮 / tab / 项目项 ≥ 40×40（宽屏手机框时）。
  • 深 / 浅色只切 token，组件规则无硬编码颜色；角色色只用于头像底 + 字母。
