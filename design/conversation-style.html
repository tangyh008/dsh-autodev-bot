与 DSH 主会话的差异（5 条，均为 DevBot 特有）

AC-22 要求差异 ≤5 条且都能解释；除下列 5 条，正文排版、用户胶囊、间距节奏、token 与 DSH 主会话一致。

  1. 成员身份头：DSH assistant 不显示名字/头像；DevBot 群聊必须能区分成员 → 20px 头像 + 12/18 名字 + 11/18 时间，连续合并。
  2. 系统 / 门禁 / 任务事件行：DSH 无群事件条 → 居中 11–12/18 label-tertiary 单行，点击展开详情，不引入彩色气泡。
  3. 派单行：DSH 无派单概念 → 复用工具行 24px 紧凑样式，正文只在目标会话投递副本出现一次。
  4. 流式“输入中”指示：DSH 使用运行状态组件 → DevBot 用正文直排 + 11/18 文本指示，减少动态效果时静态三点。
  5. 日分隔：DSH 主会话无跨成员合并的日分隔先例 → 11/18 居中弱化，跨日必显示，当日不显示。

实现底线（task-4 自检）

  • markdown 先转义 HTML 再渲染；链接白名单 http(s) / mailto / #；不执行内联 HTML。
  • 连续发送者合并只读行数据：senderId + time + 跨日；不读 DOM 几何。
  • 正文/背景/边框/圆角全部走 token；角色色只用于头像底或 4–6px 圆点，浅色下加边框或降饱和。
  • 代码块 / 表格在消息内 overflow-x:auto；页面 scrollWidth 不得超。
  • 保留 retain/release/attach、loadOlder、nextStick/shouldFollowBottom、settle 去重语义；样式层不回写数据层。
